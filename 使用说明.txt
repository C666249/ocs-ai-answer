====================================================
　OCS AI 自动答题 · 免安装整合包（本地题库版）
====================================================

【这是什么】
一个跑在你自己电脑上的「AI 题库」服务。
网课页面上的 OCS 脚本把题目发给它，它按你选的路线作答：
有本地答案就直接填，没有才去问 DeepSeek。

Python 运行时已经打包在里面，新电脑不需要装 Python，
解压就能用，不写注册表、不装服务、不改系统设置。

【包里都有什么】
  1-双击启动.bat                         平时只需要双击这个
  server.py                              服务本体
  config.json                            配置：API key、模型、端口、答题路线
  ocs-题库配置.json                       要粘进 OCS 面板的内容
  OCS网课助手_全域名通用版_v5.4.2.user.js   油猴脚本本体（答题）
  OCS题库助手.user.js                     油猴脚本（抓答案 + 切换路线）
  runtime\                               内置 Python 3.13，别删别改名
  data\                                  首次运行后自动生成
    cache.db                             AI 答案缓存
    bank.db                              本地题库镜像

----------------------------------------------------
【两条答题路线的关系】
----------------------------------------------------
  题库主库存在浏览器里（脚本猫的脚本存储）。
  每次打开网课页，题库助手会把整库同步给本地服务，
  由服务端负责「题干完全匹配 + 选项顺序换算」。

  · 题干必须完全一致才算命中。老师改一个字就不算，
    这时会转 AI，不会拿旧答案硬填。
  · 选项顺序变了没关系：服务端按「选项文字」重新对应，
    比如原答案 A 是《齐民要术》，新页面它排到 C，就填 C。
  · 每次答题前在题库助手面板里选路线，选完再点「自动答题」。

----------------------------------------------------
【新电脑上怎么用】
----------------------------------------------------

第 0 步｜解压
  整个包从 GitHub 仓库的 Releases 页下载（OCS-AI-full.zip），
  解压到一个固定位置，例如 D:\OCS-AI
  不要在压缩包里直接双击运行，必须先解压。

第 0.5 步｜填 API key（新电脑必做）
  启动后浏览器打开 http://127.0.0.1:8321
  页面最上面就是「第 0 步｜填大模型 API key」，
  把平台复制的 key 粘进输入框，点「保存并启用」。
  保存后立即生效，不用重启服务、也不用改任何文件。
  没填的时候处于 mock 模式（能通链路但不出真答案），页面会一直红字提示。
  key 只写进这台电脑的 config.json，不上传任何地方，也不会进 Git 仓库。

第 1 步｜启动服务
  双击「1-双击启动.bat」
  弹出黑窗口，浏览器会自动打开 http://127.0.0.1:8321
  终端里能看到「答题路线」和「本地题库 N 题」就是启动成功。
  ★ 这个黑窗口不要关，关掉服务就停了。

第 2 步｜装两个脚本（新电脑只需做一次）
  在控制台页面上分别点：
    「安装 OCS 脚本」   → 脚本猫弹出安装页 → 点「安装」
    「安装题库助手」     → 脚本猫弹出安装页 → 点「安装」
  装好后回到网课页刷新，右下角是 OCS 悬浮球，
  左下角是「题库 N · AI优先」的小胶囊按钮，两个都在就对了。

第 3 步｜配题库（只需做一次）
  控制台点「一键复制题库配置」
  → 打开任意网课页 → 点 OCS 悬浮球
  → 全局设置 → 题库配置 → 点「点击进入配置」→ Ctrl+V 粘贴 → 保存
  看到「AI 题库 · 本地」就配置成功了。

第 4 步｜抓答案（第一次做题之后）
  ① 先正常答一次（走 AI，分数不一定满分）
  ② 交卷后进「查看答案 / 已批阅」页面
  ③ 点左下角题库助手 → 「抓本页答案」（会先自动滚一遍页面，把长卷子加载全）
  ④ 弹出预览：每题列出全部选项，正确答案那一项标绿，答案后面跟着对应选项的原文
     → 核对无误点「确认入库」

  预览顶部那行计数就是诊断信息：
    页面答案锚点 N 处 ｜ 解析出 M 道 ｜ 题干重复 K 处 ｜ 未解析 J 处 ｜ 缺选项 X 道
    · 锚点 = 页面上出现「正确答案：」的次数，也就是这页真正给答案的题数
    · 锚点比题目总数少：说明有几道题没显示正确答案（多为未作答 / 主观题），这些不会入库
    · 未解析 > 0：题干超长或排版特殊，预览顶部会列出这几种题的片段

  规则的底线：
    · 答案只取「正确答案 / 参考答案」后面那段，「我的答案」永远不取
    · 每题的全部选项（A/B/C/D + 文字）都会入库 —— 下次选项顺序打乱时，
      靠选项文字重新对位，不会照着旧字母硬填
    · 某道题没给正确答案时，绝不会借用下一题的答案（会直接跳过）

第 5 步｜第二次作答
  回到作业页面 → 点左下角胶囊 → 选「本地+AI」
  → 点自动答题。能匹配上的秒答，匹配不上的自动转 AI。

----------------------------------------------------
【题库助手的三个路线】
----------------------------------------------------
  AI 优先    全部交给 AI。默认就是这个。
  本地+AI    本地有完全一致的题就用本地答案（选项乱序也能换算），
             没有就转 AI，并在屏幕上提示「本题本地题库没有」。
  仅本地     只用本地题库。没有就留空，绝不调 AI、绝不硬填。
             适合你已经确认题库是全的、想省 token 的场景。

  切换立即生效，不用重启服务，也不用动 OCS 里的题库配置。

----------------------------------------------------
【题库怎么搬走 / 备份】
----------------------------------------------------
  面板里「导出」= 存成 JSON 文件，换电脑时用「导入」喂回去。
  浏览器清缓存、卸载脚本猫都会丢题库，重要的话定期导出。

----------------------------------------------------
【四条红线】
----------------------------------------------------
· 考试不要用。超星考试有答题节奏和切屏检测，作业和章节测验随便用。
· 面板里「答题间隔」不要设成 0，全秒答是最容易被识别的特征。
· 不要同时开多个作业/考试页面（OCS 自己也会提示）。
· 旧的「OCS 网课助手」普通版要停用，只留「全域名通用版」。

【常见问题】
----------------------------------------------------
Q: 双击后黑窗口一闪就没了
A: runtime 目录没解压完整，重新解压整包。

Q: 提示「端口 8321 已被占用」
A: 说明已经有一个实例在运行。直接打开 http://127.0.0.1:8321 即可。

Q: OCS 面板显示「题库连接失败」
A: ① 黑窗口是不是被关了
   ② 装的脚本是不是「全域名通用版」
   ③ 浏览器打开 http://127.0.0.1:8321 看服务还在不在

Q: 提示「AI 调用失败：接口 HTTP 401」
A: key 无效。401 = key 错，402 = 余额不足。
   打开 http://127.0.0.1:8321 ，在第 0 步那里换一个 key 保存即可。

Q: 明明题库里有这题，为什么还是走了 AI
A: 四种可能：
   ① 题干被改过（多一个空格也算，严格模式）。控制台能看题库里的原文对比。
   ② 选项文字变了，服务端对不上就不敢填。
   ③ 当前路线是「AI 优先」。切到「本地+AI」再试。
   ④ 当初抓这题时没抓到选项（预览里显示「缺选项」）。没有选项文字就
      无法判断顺序有没有打乱，程序宁可转 AI 也不会照旧字母硬填。
      这类题可以再进答案页重抓一次，或干脆让它走 AI。

Q: 抓取时提示「这页没找到带正确答案的题」
A: 这个页面没有「正确答案」字样，比如还没交卷。
   必须进「查看答案 / 已批阅 / 成绩详情」那种页面才能抓。
   还是不行就用控制台那个「从页面文本导入」框，手动粘整页文字。

Q: 题库数据存在哪
A: 浏览器里（脚本猫脚本存储）。本地服务的 data\bank.db 只是镜像，
   删了不影响，下次开页面会自动重新同步回来。

Q: 想换 key 或换模型
A: 打开 http://127.0.0.1:8321 ，在「第 0 步」的输入框里粘新 key 点保存即可，
   立即生效不用重启。换模型改 config.json 的 llm.model 后重启 bat。

Q: 杀毒软件报警
A: 里面是 python.org 官方原版运行时，不是自编译的 exe，加信任即可。

Q: 想搬到第三台电脑
A: 整个文件夹复制一遍，再去题库助手面板导出 JSON 带过去导入。

【花多少钱】
----------------------------------------------------
一道题约 0.0002 元，一万道题约 2 元。
走本地题库命中时完全不花钱。
控制台「运行状态」里有累计花费、单题均价、本地命中次数。

【技术备注（给你自己看）】
----------------------------------------------------
· 服务只监听 127.0.0.1，外网和局域网都访问不到。
· 接口：
    GET  /query                  OCS 调用入口（按 config.json 的 route.mode 路由）
    GET  /route  POST /route     查看 / 切换答题路线
    GET  /bank                  题库镜像状态
    POST /bank/add              追加题目
    POST /bank/sync             以客户端为准全量替换镜像
    POST /bank/import           粘贴文本解析入库（dry_run=1 只解析不写）
    POST /bank/clear            清空镜像
· AI 答案缓存存在 data\cache.db，题库镜像在 data\bank.db。
· 想局域网用：config.json 里 host 改成 0.0.0.0，并放行防火墙 8321。
· 公网使用务必先给 api_token 设一个值，否则拿到地址的人都能刷你的 key。
· 关了模糊匹配（route.exact_only=true）。要允许容错就改成 false
  并调低 match_threshold。
