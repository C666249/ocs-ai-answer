# OCS AI 答题 · 本地题库 + AI 双路线

跑在自己电脑上的「AI 题库服务」：网课页面上的脚本把题干发过来，它按你选的路线作答——
**本地题库命中就直接填，没命中才去问大模型**。

核心设计原则：**记住的是「答案的文字内容」，不是 ABCD。**
字母只是索引，选项顺序一换就废；所以题库里存的是「题干 + 每个选项的原文 + 哪几项原文是对的」，
下次遇到同一题先按题干严格匹配，再按选项文字把答案对位到当前页面。
对不上就认输（转 AI 或留空），绝不拿旧字母硬填。

## 快速开始（新电脑）

1. 到 **Releases** 下载 `OCS-AI-full.zip`，解压到固定位置，例如 `D:\OCS-AI`
2. 编辑 `config.json`，把 `llm.api_key` 换成你自己的 DeepSeek key
3. 双击 `1-双击启动.bat`，黑窗口不要关
4. 浏览器打开 `http://127.0.0.1:8321`，按页面提示安装两个脚本
5. 装 ScriptCat（脚本猫）扩展后，两个 `.user.js` 才能被接管

详细步骤见 `使用说明.txt`。

## 目录

```
1-双击启动.bat            启动器（CRLF 换行，cmd 才能正确解析）
server.py                 本地服务：路由、题库匹配、选项重映射、缓存
OCS题库助手.user.js        抓答案 + 切换答题路线
ocs-题库配置.json          要粘进 OCS 面板的题库配置
tools/export_bank_text.py 把题库导出成人能读的 txt（核对答案原文）
config.example.json       配置模板（key 留空）
```

## 两条路线

| 模式 | 行为 |
|---|---|
| `ai_only` | 全交给 AI |
| `hybrid` | 本地命中用本地，未命中转 AI（推荐） |
| `bank_only` | 只用本地，未命中留空，绝不调 AI |

服务端读 `config.json` 的 `route.mode`，所以面板上切换是全局生效的，两个脚本共用。

## 匹配规则

- **题干严格匹配**（`route.exact_only=true`）：多一个空格就不算命中，宁可转 AI
- **选项按文字重映射**：银行里存的是选项原文，当前页面按原文找位置，顺序打乱也能答对
- **无法对位就放弃**：库里没有选项原文、或当前页面找不到对应文字，直接判未命中，不猜
- **只抓「正确答案」**，永不采集「我的答案」，避免把自己的错答当标准答案

## 数据在哪

- 题库主库：浏览器（脚本猫脚本存储，`ocsai_bank_v1`）
- 本地镜像：`data/bank.db`（删了不影响，下次开页面自动同步回来）
- AI 缓存：`data/cache.db`
- 密钥：`config.json`（**已在 .gitignore 里，不会进仓库**）

## 安全说明

- 服务只监听 `127.0.0.1`，外网/局域网访问不到
- 仓库里只有代码，不含任何 key、题库或答题记录
- 要公网/局域网使用，先给 `server.api_token` 设值，否则拿到地址的人都能刷你的额度
